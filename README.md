# Cryonic Dungeon Descent

**Cryonic Dungeon Descent** is a 2D dungeon game developed using Python and Pygame. The project explores the effectiveness of Python as a programming language for developing a 2D dungeon game with functional enemy AI.

The game focuses on dungeon exploration, player interaction and enemy behaviour, investigating how Python can be used to implement game mechanics and artificial intelligence.

## Features

- **2D Dungeon Environment** — Explore a dungeon-based game world.
- **Player Movement** — Control the player throughout the dungeon.
- **Enemy AI** — Implement functional enemy behaviour and interactions.
- **Enemy Interactions** — Allow enemies to respond to the player's actions.
- **Game Mechanics** — Implement core gameplay systems.
- **Collision Detection** — Detect interactions between the player, enemies and environment.
- **Python Development** — Use Python to develop the game's systems and functionality.

## Built With

- **Python** — Main programming language.
- **Pygame** — 2D game development library.

## Getting Started

1. Download or clone this repository.
2. Install Python.
3. Install the required dependencies.
4. Run the main Python file.
5. Play Cryonic Dungeon Descent.

## Project Aim

This project investigates the following research question:

**"To what extent is Python an effective programming language for developing a 2D dungeon game with functional enemy AI?"**

The project aims to evaluate Python's suitability for 2D game development, particularly in relation to performance, programming complexity, flexibility and the implementation of enemy artificial intelligence.

## Development

Cryonic Dungeon Descent is being developed as a practical programming project alongside research into Python, Pygame, 2D game development and enemy AI.

The game will be used to assess the strengths and limitations of Python when developing a functional 2D dungeon game.
